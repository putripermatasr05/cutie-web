# Putri Permata Sari — Interactive Notebook Resume & Portfolio

Web resume & portofolio interaktif mobile-first SPA dengan konsep *notebook/binder* dan map manila vintage yang dilengkapi animasi flip lembaran buku, gestur swipe/drag interaktif, dan navigasi daftar isi.

## ✨ Fitur
- **Konsep Notebook & Manila Folder**: Visual bergaya map arsip vintage, kertas bergrid, binder clip, stiker polaroid, washi tape, dan rosette badge.
- **Interaksi Flip 3D**: Halaman dapat dibalik dengan animasi realistis saat disentuh/di-swipe (mobile) maupun tombol navigasi / keyboard.
- **Single Page Application (SPA)**: 7 lembar lengkap tanpa reload, didukung hash routing (`#/cover`, `#/profil`, `#/pendidikan`, `#/kerja`, `#/lainnya`, `#/skill`, `#/kontak`).
- **Mobile First Responsive**: Tampilan dioptimalkan khusus untuk layar smartphone dan menyesuaikan secara elegan di layar tablet/desktop (open book layout).
- **Direct Action Links**: Tombol kontak cepat terintegrasi langsung ke WhatsApp, Email, dan LinkedIn.

## 🛠️ Teknologi
- HTML5 (Semantic & SVG Sprites)
- CSS3 (Vanilla CSS, 3D Transforms, Custom Properties)
- JavaScript (Vanilla ES6+, Pointer Events Touch/Swipe Engine)
